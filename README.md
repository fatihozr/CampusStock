# CampusStock

Üniversiteye Özel Kırtasiye Sipariş ve Stok Yönetim Platformu.

Öğrenciler yalnızca kendi üniversitelerindeki kırtasiyelerden ürün seçer, sepete ekler ve sipariş verir; kırtasiye yöneticileri kendi stoklarını yönetir.

Kurulum, mimari ve test bilgileri geliştirme ilerledikçe bu dosyaya eklenecektir.
